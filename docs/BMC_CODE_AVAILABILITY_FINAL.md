### Code Availability

The source code and implementation of HELPix-R are publicly available through the project's GitHub repository and have been archived on Zenodo to support reproducibility and long-term accessibility. The repository contains the preprocessing pipeline, cryptographic deduplication, leakage-controlled group splitting, HELPix-R architecture implementation, training and evaluation scripts, temperature scaling calibration module, MC-Dropout uncertainty estimation, external testing procedures, and Grad-CAM explainability routines.
