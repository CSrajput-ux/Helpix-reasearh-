# BMC Medical Imaging: Data Availability Statement

### Data Availability

This study uses publicly available skin-lesion image datasets, including ISIC 2024 SLICE-3D, HAM10000, and PAD-UFES-20. The datasets are available from their respective public repositories under their applicable access conditions and licenses:
- **ISIC 2024 SLICE-3D**: Available via the International Skin Imaging Collaboration (ISIC) Archive (https://www.isic-archive.com) under CC0 / Creative Commons terms.
- **HAM10000**: Available via the Harvard Dataverse repository (https://doi.org/10.7910/DVN/DBW86T) under Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0).
- **PAD-UFES-20**: Available via Mendeley Data (https://doi.org/10.17632/zr7vgbcyr2.1) under CC BY 4.0.

Dataset descriptions, curation records, and original source publications are cited within this manuscript. Due to the licensing and third-party distribution terms of the original repositories, the raw image datasets are not redistributed directly with this study. Derived research artifacts generated during this study—including cryptographic deduplication audit logs, patient-level split definitions, post-hoc calibration tables, evaluation metric summaries, and experiment configuration files—are made available through the project's code repository and long-term Zenodo archive.
